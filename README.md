# 打工记

一个基于项目文档制作的可点击网页原型。纯静态前端实现，打开网页即可游玩。

## 本地运行

直接双击 `index.html` 即可运行，或者在当前目录启动一个静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 已实现内容

- 早晨阶段：起床、回笼觉、逐渐加速的时间流速、查看手机二选一
- 工作阶段：每日工作结算
- 夜晚阶段：睡觉、夜间放松、睡眠债
- 商店系统：床铺升级、消耗品、工作路线切换
- 胜负判定：需要休整、需要放松、财富自由
- 自动存档：使用浏览器 `localStorage`

## 部署

仓库包含 GitHub Pages 工作流。推送到 GitHub 仓库后，可在仓库设置中启用 Pages，并使用 GitHub Actions 作为部署来源。
